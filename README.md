# 🏝️ 乐高群岛大冒险 2.0 (Voxel LEGO Archipelago)

基于 Three.js 打造的开放世界 3D 乐高群岛游乐场：包含主岛港口、**海盗骷髅岛**、**可乘坐的第一人称 3D 乐高过山车岛**与**浮空天空神殿**，融合海陆空三栖载具、物理大炮打靶、码头钓鱼图鉴、自由拼装工坊与链接分享！

🔗 **在线体验**：https://wshwzn.github.io/voxel-lego-island/

## 2.0 史诗级亮点
- **🏝️ 乐高群岛大世界**：
  - **主岛港口小镇**：红白灯塔、风车、瀑布泄湖、海滩营火与雪山/活火山一键切换。
  - **🏴‍☠️ 海盗骷髅礁岛**：发光翡翠眼骷髅悬崖、搁浅的暗木乐高海盗船与水晶秘窟。
  - **🎢 乐高过山车乐园岛**：3D 平滑轨道过山车，支持点击「🎢 过山车」**直接坐进前排第一人称体验极速俯冲！**
  - **☁️ 浮空天空神殿**：悬浮于云端的白色大理石黄金神殿与旋转天空水晶。
- **✈️ 海陆空三栖操控 + 空中飞环挑战**：
  - **🚶 岛上漫步**：探险家/海盗船长/宇航员 3 套换装，自动登台阶、跳跃、下海游泳、踩弹跳垫起飞、`V` 键切换第一/第三人称。
  - **⛵ 亲自开船**：驾驶帆船跨岛航行，鸣笛放信号弹。
  - **✈️ 驾驶水上飞机**：控制双翼水上飞机爬升俯冲，穿越横跨全部岛屿的 **10 个金色飞环赛道**！

  - **💥 大炮模式**：鼠标瞄准海面漂浮的海盗靶船，发射抛物线炮弹将靶船轰碎成 **20+ 块弹跳飞溅的物理乐高散件**！
  - **🎣 码头钓鱼**：抛竿听音辨咬钩，收集 8 种稀有度海洋生物与秘宝图鉴。
  - **💎 8 个群岛金宝箱**：遍布全部四座岛屿的隐藏宝箱收集与烟花庆典。
