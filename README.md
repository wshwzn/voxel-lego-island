# 🏝️ 乐高体素海岛 · 豪华探索版 (Voxel LEGO Island)

基于 Three.js 打造的模块化 3D 乐高体素微缩世界，集成了动态昼夜循环、天气系统、极光流星、活火山喷发、自由拼装积木、亲自驾驶帆船、寻宝彩蛋与 Web Audio 实时合成音效。

🔗 **在线体验**：https://wshwzn.github.io/voxel-lego-island/

## 核心特性
- **🧱 乐高体素建筑与地貌**：2,600+ 块带斜角接缝纹理的体素积木与圆柱乐高凸点，包含港口小镇、红白灯塔、风车、瀑布泄湖、海滩营火与海底珊瑚礁。
- **🌦️ 动态天气 + 极光流星 + 活火山**：一键切换晴朗 / 细雨 / 雷暴闪电 / 飘雪（积雪渐变覆白），夜晚开启 3D 流动极光带与流星雨，支持一键唤醒雪山变为喷发岩浆的活火山。
- **🎈 鲜活的乐高生灵与载具**：散步的乐高小人、码头垂钓渔夫、营火露营者、跃水海豚、水下海龟与热带鱼群、夜光热气球、双翼水上飞机与环岛帆船。
- **🎮 三大互动模式**：
  - **🧭 自由漫游**：点击探索隐藏在岛上各处的 5 个发光乐高金宝箱，集齐触发盛大烟花秀。
  - **🧱 拼装积木**：12 种经典乐高颜色（含发光金灯积木），悬停半透明预览，左键咔哒叠放、右键拆除、支持撤销与本地自动保存。
  - **⛵ 亲自开船**：第三人称追尾视角，`WASD`/方向键亲自掌舵出海，`Space` 鸣笛放信号弹。
- **🔊 零素材程序合成音效 + 📸 明信片导出**：纯 Web Audio API 实时生成海浪、雨声、雷鸣、海鸥、营火、乐高拼装咔哒声与烟花音效，一键导出带时刻水印的高清 PNG 明信片。
